Flap Sheet Support

Support information for Flap Sheet, a magic performance utility for iPhone.

Getting Started

Open Flap Sheet and use the in-app launcher to select the performance mode you need. Configure the available controls for that mode before beginning a performance.

Performance Controls

Flap Sheet uses on-device controls and, in supported modes, system volume buttons and motion input. The exact controls available depend on the selected mode and its current configuration.

Troubleshooting

  • Make sure Flap Sheet is updated to the latest available version.
  • If a motion-based control does not respond, confirm that Motion access is allowed for Flap Sheet in iOS Settings.
  • If volume-button behavior is not as expected, verify the app’s current performance configuration and the device volume state before use.
  • If the issue persists, restart Flap Sheet and try the setup again.

Contact

For support, include your iPhone model, iOS version, Flap Sheet version, and a short description of the issue.
