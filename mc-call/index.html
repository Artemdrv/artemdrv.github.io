Это подготовленный адресат. Набранный на клавиатуре номер остаётся только на экране. Номер и контакты не публикуются в GitHub.

Это не API Secret Twilio. Ключ доступа не сохраняется и не включается в резервную копию. Реальный режим требует развёрнутого backend, разрешённого номера и микрофона.

Репетиция: реальное соединение не устанавливается, речь собеседника не воспроизводится.

Установка и проверка

Safari → Поделиться → На экран «Домой» → Открыть как веб-приложение. Запускайте с иконки. Для настроек: пять нажатий на поиск за две секунды.

Контакты, история и настройки хранятся в IndexedDB. Импорт выполняется на телефоне. Очистка данных сайта может удалить базу. Резервная копия содержит личные данные без шифрования. Это сценический инструмент, не приложение Apple и не замена экстренной связи. SMS, FaceTime и системная история iOS не подключены.
