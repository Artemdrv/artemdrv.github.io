# MC Call · 4.0.0

Сценическая Phone PWA для личного телефона исполнителя. **Это не системный «Телефон» Apple.**

## Что входит

Адаптивный набор номера; графика цифр и нижних значков из предоставленного референса; нажатие/отпускание/cancel; DTMF на touch-down; удержание 0 → +, * → пауза, # → ожидание; повторное удаление; рабочие Calls, Contacts, Search и карточки; избранное; локальная история; импорт vCard 2.1/3.0/4.0; резервное копирование.

Стандартный запуск сразу показывает клавиатуру. **Пять нажатий на поиск за две секунды** открывают настройки. Фактический номер сохраняется только на устройстве. В обычном интерфейсе и истории показывается выбранный или введённый зрителем номер.

## Установка

Открыть HTTPS-ссылку в Safari → Поделиться → На экран «Домой» → включить «Открыть как веб-приложение». Запускать с этой иконки. При изменении иконки может понадобиться переустановка ярлыка. Перед удалением данных сохранить резервную копию.

После обновления v3 → v4 обновление service worker активируется, когда закрыты старые окна приложения. Номер из старого `mccall.route` переносится при первом запуске v4. Остальные приложения сайта не удаляются. Новые ассеты имеют отдельные имена; испорченные кропы v3 не используются.

## Локальные данные и приватность

База IndexedDB: `mc-call-r4`, хранилища `contacts`, `recents`, `settings`. Импорт VCF разбирает файл на устройстве. Внешние URL фотографий отбрасываются; встроенные JPEG/PNG/WebP принимаются. Нет аналитики, синхронизации или отправки адресной книги. GitHub получает только исходный код и публичную графику, не импортированные контакты и не настройки исполнителя.

История — собственная история PWA, не журнал SIM/iOS. Контакты — локальная импортированная копия, не живая синхронизация системной базы. Приложение само не синхронизирует эти данные с iCloud. Поведение системного резервного копирования устройства находится вне контроля PWA.

База не зашифрована. IndexedDB изолируется по origin, а **не по папке URL**: другие приложения того же `https://artemdrv.github.io` потенциально имеют доступ к хранилищам этого origin. Для распространения и работы с чужими телефонными книгами нужен отдельный доверенный origin. Удаление данных сайта или вытеснение хранилища может удалить базу. Запрос постоянного хранения не заменяет резервную копию.

`.mcphone` — незашифрованный JSON с контактами, историей и подготовленным номером. Перед экспортом появляется предупреждение. Ключ доступа исполнителя и адрес backend в копию не входят; восстановление всегда включает репетиционный режим. Восстановление выполняется одной транзакцией после проверки формата.

## Два режима вызова

**Репетиция (по умолчанию).** Визуальный вызов, гудки, таймер, собственная история. Телефон никому не звонит, речь не синтезируется, записи разговора нет. Статус режима явно указан в настройках.

**VoIP.** Подготовлен клиентский путь к настоящему соединению, но он требует отдельно развёрнутого backend и настроенного аккаунта провайдера. До подключения и теста звонка телефония не считается готовой. Проект не содержит API-ключей, не оплачивает сервисы и не делает пробных реальных вызовов автоматически. При ошибке real mode не переключается на скрытую имитацию.

Во время реального вызова backend получает только фактический номер. Ни визуально введённый номер, ни имена, ни вся телефонная книга туда не отправляются. Звук и фактический номер проходят через провайдера. iOS может снова запросить разрешение микрофона; обещать вечное отсутствие запросов нельзя. PWA нужно держать открытой. Системный звонок, блокировка или уход в фон могут нарушить WebRTC.

## Backend

См. `backend/SETUP.md`. Код serverless endpoint'ов подготовлен; реальные реквизиты и оплаченные назначения не подключены. Endpoint'ы требуют bearer-ключ, разрешённый origin и номер из серверного allowlist. Голосовой webhook проверяет подпись Twilio и короткоживущий routing ticket.

## Визуальный статус

Основной эталон клавиатуры — скриншоты пользователя (фактический размер исходников в этой сессии **946×2048**, а не 1284×2778), нормализованные к 428×926. Знаки и цифры — отдельно масштабируемые alpha-mask ассеты с сохранением сглаживания. Подложки кнопок и геометрия — живой интерфейс, не растягиваемая картинка экрана. Никаких распространяемых шрифтов нет: динамический текст использует системный шрифт устройства.

Клавиатура в эталонном viewport: первый круг примерно x=58, y=252, размер 88×88. Нижняя навигация привязана к safe area. На других размерах меняются размеры компонентов и вертикальные расстояния. В горизонтальном окне предусмотрена компактная резервная раскладка; PWA не может гарантировать системную блокировку ориентации на каждом iPhone.

Calls построен по официальному unified reference Apple. Contacts, Search, карточка и экран разговора функциональны, но **их попиксельное совпадение на реальном iPhone не подтверждено**. SMS, FaceTime, конференции, системные контакты и CallKit не реализованы. Кнопка динамика не выдаёт управление системным аудиомаршрутом за веб-возможность.

Источник иконки записывается в `assets/icon-source.json`: при успешной загрузке используется опубликованный Apple Phone artwork; иначе статус явно остаётся `reference-reconstruction`. Графика Apple не становится открыто лицензированной из-за наличия на публичном сайте. Проект не выдаёт себя за продукт Apple.

## Проверка

`npm test` — автономные unit-тесты импорта, валидации, поиска и серверных защит.

`python3 -m pip install playwright==1.56.0 pillow` и `python3 -m playwright install --with-deps chromium` — среда browser QA. Запустить `python3 -m http.server 8765 --directory .`, затем `python3 tests/browser.py`. Отчёт и реальные скриншоты Chromium сохраняются в `qa/`. Тесты не совершают платных телефонных вызовов.

Browser QA проверяет настоящую IndexedDB и Cache Storage без их подмены. Для офлайн-проверки отдельный HTTP-сервер физически останавливается, затем выполняется переход на новый URL и чтение сохранённых контактов. Это проверка недоступности сети до origin, а не аппаратного авиарежима iPhone. WebKit и Chromium запускаются в GitHub Actions; они не заменяют проверку установленной PWA на физическом iPhone.
